## 📜 博客历程

- **2014 年**：开始接触博客搭建，先后尝试 WordPress、Hexo、Typecho。
- **2019 年底**：仓库首次提交，并把博客迁到 GitHub，改用 Git 管理内容。
- **2020 年**：接入 GitHub Actions 自动构建、GitHub Pages 发布，博客进入静态化时代。
- **2021 年**：曾借助 jsDelivr 加速静态资源。
- **2023 年**：集中整理文章、修订内容。
- **2024 年底**：更新个人简介、兴趣爱好与内容结构。
- **2026 年**：完成阶段性重构：压平主题改为单站点 Hugo、自托管 Fontsource 字体、接入 Pagefind 全文搜索；随后又换成纸面细线的视觉基调，并持续完善搜索、无障碍与字体加载。

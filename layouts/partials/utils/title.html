{{/* 页面标题：返回 dict rawTitle / title（带站点名）/ htmlTitle。调用方 dict "$" page "title" ... */}} {{- $ := index . "$" -}} {{- $path := .Path -}} {{- $htmlTitle := .title -}} {{- if eq $.Kind "home" -}} {{- $htmlTitle = $htmlTitle | default $.Site.Title -}} {{- else if eq $.Kind "taxonomy" -}} {{- $taxonomyTitle := cond (eq $.Data.Plural "tags") "标签" ($.Type | title) -}} {{- $htmlTitle = $taxonomyTitle -}} {{- else if eq $.Kind "term" -}} {{- $taxonomyTermTitle := $htmlTitle | default $.Data.Term | default (delimit (last 1 (split (strings.TrimSuffix "/_index.md" $path) "/")) " ") -}} {{- $taxonomyTitle := cond (eq $.Data.Plural "tags") "标签" ($.Type | title) -}} {{- $htmlTitle = printf "%s：%s" $taxonomyTitle $taxonomyTermTitle -}} {{- else if eq $.Kind "section" -}} {{- $htmlTitle = $htmlTitle | default (delimit (last 1 (split (strings.TrimSuffix "/_index.md" $path) "/")) " ") -}} {{- else if eq $.Kind "404" -}} {{- $htmlTitle = "页面不存在" -}} {{- end -}} {{- $pageNumber := .pageNumber | default 1 -}} {{- if gt $pageNumber 1 -}} {{- $htmlTitle = printf "%s - 第 %d 页" $htmlTitle $pageNumber -}} {{- end -}} {{- /* 站点名是纯文本配置：不经 markdownify（smartypants 会把撇号变弯引号，与 og:site_name/RSS/页脚的直引号不一致）；仅内容标题需要排版变换。 */ -}} {{- if eq $.Kind "home" -}} {{- $htmlTitle = $htmlTitle | plainify | htmlUnescape | strings.TrimSpace | safeHTML -}} {{- else -}} {{- $htmlTitle = $htmlTitle | markdownify | safeHTML -}} {{- end -}} {{- $rawTitle := $htmlTitle | plainify | htmlUnescape | strings.TrimSpace -}} {{- $title := $rawTitle -}} {{- if ne $.Kind "home" -}} {{- $title = printf "%s | %s" $title $.Site.Title -}} {{- end -}} {{- return dict "rawTitle" $rawTitle "title" $title "htmlTitle" $htmlTitle -}}
